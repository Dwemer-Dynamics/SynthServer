SYNTH 101 Quick Guide

  1. The AI is not deterministic!

    The same input does not always produce the same result! Therefore the AI will not always respond as expected. Different Large Language Models (LLM) will provide different outputs, not all are designed for role-playing. Smaller models will not have as much accurate information about the wasteland and will often hallucinate.

  2. Where do I configure SYNTH?
    • 1. Configuration Hub: Manage NPCs, profiles, LLM connectors, TTS, STT, world knowledge, prompts, and global settings.
    • 2. Quickstart Menu: Use the guided setup path for first-time connector and service configuration.
    • 3. In-game MCM: Configure hotkeys and plugin-side behavior from Fallout.
  3. You must use a JSON LLM!
    It allows us to force programmatic output from the AI which allow memories, animations, moods, multi-group conversations, etc to even work. If you have no idea what an "Instruct/JSON" model is we recommend to use meta-llama/llama-3-70b-instruct or any ChatGPT model.
  4. AI Command List

    Actions are more likely to trigger through natural conversation with smarter LLMs. Dumber LLMs will have a harder time triggering actions unless you specifically say the command exactly.

    • Inspect NPC
    • Inspect Surroundings
    • Move To (Short distance travel to nearby entities or enterable buildings in the same cell, e.g., "Move to the saloon")
    • Travel To (Long distance travel to fast travel locations, e.g., "Travel to Primm")
      Note: This command can be unpredictable as it's looking for the worldspace name as the target. Some locations may not be valid or require correct spelling. Most major towns and settlements do work however.
    • Attack
    • Open Inventory (Followers = Inventory Menu, Other NPCs = Barter Menu)
    • Check Inventory
    • Sheathe Weapon
    • Take A Seat
    • Read Quest Journal
    • Increase Walk Speed
    • Decrease Walk Speed
    • Wait Here
    • Stop Walking
    • Halt! (Will hard stop any AI actions)
  5. AI Awareness
    • Combat Encounters
    • Dialogue (traditional and AI spoken)
    • Time/Date
    • Weather
    • Location (including modded location)
    • Quests (including modded quests)
    • Player Statistics
    • Items Acquired
    • Equipment
    • Memories
    • Diary Entries
    • Books
    • Who was present during events (You can keep secrets from AI NPCs!)
    • Fallout lore topics (World Knowledge)
  6. How Profiles Work
    • It's important to configure the default profile before adding AI NPCs to the framework.
    • Each time an AI NPC is added, it will inherit the default profile values.
    • After this, the NPC name will be automatically filled and a new profile will appear in the drop down menu (you may need to refresh the interface).
    • By configuring the default profile properly, you ensure that new AI NPCs have the appropriate settings from the start.
    • When adding a new AI NPC, the default profile will be copied over but with a different character name and personality profile.
    • You can use the "Copy to All Profiles" button to make changes to all profiles.
  7. Error Phrases
    Your AI NPCs will say certain phrases for when there is an error with the AI generation. It is a good idea to check the "Response Log" page for more information.
    • "Didn't hear you, can you repeat?" = There is an error connecting to your LLM service.
    • "Be quiet, I'm having a flashback, give me a minute" = To many request being sent to your LLM service.
    • "I can't think clearly now..." = The AI service rejected the request.
  8. Other Useful Tips
    • You can easily upload custom NPC profiles with our NPC Biography Upload
    • Use the Troubleshooting menu to test LLM/TTS/STT services before using them ingame
    • You can make advanced edits to how NPC's respond with our Prompts Manager
    • Loading older or new saves can delete memories and events! This is to prevent time paradoxes. Here is a guide for profile backups.
  9. Log File Locations
    • The SYNTH plugin log is located in the Fallout 4 F4SE or Fallout 4 VR F4SEVR log folder for the active MO2 profile.
    • You can find the SYNTH Server logs under Troubleshooting - Server Logs or at \\wsl.localhost\DwemerDistro\var\log\apache2
    • The deployment target for SYNTH Server files is \\wsl.localhost\DwemerDistro\var\www\html\Synthserver.
    • Connector service logs are available through DwemerDistro's service tooling and the server log pages.
